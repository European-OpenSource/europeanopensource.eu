- [CLI reference](cli.md): every `cli.sh` command, flag and error.
- [Managed vs seed](managed-vs-seed.md): the two file classes every shipped path belongs to,

- [Astrobook](astrobook.md): the component catalog for developing and visually gating components.
- [Testing](testing.md): every suite, what it covers, and the exact command to run it.
- [Versioning](versioning.md): the release process and tag policy.
